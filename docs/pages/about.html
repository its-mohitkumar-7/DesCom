About

DesCom (Destination Confirmation System) is an IoT-based destination monitoring system designed to confirm when a person reaches a designated destination. The system uses an ESP32-CAM to scan a QR code presented on a printed card, eliminating the need for the person to carry or use a smartphone.


When a QR code is scanned, the ESP32-CAM connects to the local Wi-Fi network and sends the scanned QR data to the backend. The backend verifies the QR code against the registered records and retrieves the corresponding recipient information. Once the QR code is successfully verified, the system records the scan and triggers a Telegram notification for the associated recipient.


The project combines embedded hardware, QR-code identification, Wi-Fi communication, a cloud-based backend, and Telegram notifications into a single workflow. This allows the destination confirmation process to be automated while keeping the scanning process simple for the person using it.


My goal is to make DesCom accessible to everyone. Since it is free and designed to address an important problem for students, especially girls, I will try to provide as many resources and guides as possible so that anyone can build and use it on their own.
