Google Sheet Setup

Google Sheet

It is a free, web-based spreadsheet application provided by Google as part of its web-based Google Docs Editors suite. It allows users to create, format, and manipulate spreadsheets online while collaborating with other users in real-time.

It offers powerful automation and extending capabilities through features like Google Apps Script, macros, and third-party add-ons, making it a highly versatile tool for data analysis, project management, and daily tracking.

In this project it used as automation, where it will process API requests and help you to automate tasks like send message, verify student through google sheet, provide process status.

Account Creation

For this project its not necessary to use freshly created account. If you have any existing google account then your can skip to Sheet setup.

Instructions

  1. Open web browser and search for Create Google account or use link.
  2. Type name and click on next.
  3. Enter Date of Birth and gender then click on next.
  4. Enter unique username for gmail address then click on next.
  5. Enter password then click on next.
  6. After that follow on screen instructions.

Sheet Setup

For this process you need to create columns in a Google Sheet Blank Table.

Instructions

  1. Open web browser and search for Google sheets or use link.
  2. Click on blank template sheet.
  3. Click on Insert → Pre-built tables.
  4. Click on Blank Sheet on right side window.
  5. Double tap on column names and change them with QR_ID, Student_Name, Father_Name, Phone_Number, Chat_ID, Last_Scan, Last_Scan_Status.

Chat ID

For this project Phone numeber are for only convenience of teachers they verify parent's using phone number. Here Chat ID is used to send telegram messages. You have to use your Bot API that you get by following previous instructions.

Instructions

  1. Open web browser on your device.
  2. Type https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates in address bar by replacing your actual bot token.
  3. A page will open with JSON text.
  4. Verify ok: true must written in first line. If not then recheck your url.
  5. Share bot link to parent's phone or guide them to search for bot using bot's username.
  6. Say them to click on start button in bot.
  7. After refreshing your browser you will see a JSON response will generate on same page.
  8. Look for id: under chat:.
  9. Note down that 10 digi number in font of id:, its parent's chat ID.

Data Entry

Follow instructions carefully. Fill data as per their respecting columns.

Instructions

  1. Fill unique QR_ID initial with QR, like QR123456 here digits must be 6.
  2. Fill Name in uppercase or captal letters, like FOOBAR.
  3. Fill Parent name in uppercase or capital letters, like BAZBAR.
  4. Fill parent's phone number.
  5. Fill chat id that you get in previous step.

Code Setup

Code setup is important step becuase tiny mistake will ruin whole project. lcd status, Telegram alert both rely on this.

Instructions

  1. Open web browser.
  2. Open GitHub and search for DesCom.
  3. Go to src → backend → api.gs or use link.
  4. Copy whole file and save it temporarily.
  5. Open file.
  6. Replace school name with your preferred school name, like Foo Bar.
  7. Replace bot token with your bot token, like 1234567890:ABCDabcdEFGHiMN_ab_-2b
  8. Replace sheet name that you used to write student details, like Bazbar.
  9. Save this file.

Deploy

This Deploy will work as your backend server, it will process API requests, verify students, send alert message through Telegram API. Update Status in sheet so you will aware about last scan status in sheet table.

Instructions

  1. Open sheet in Google Sheets.
  2. Click on Extensions → Apps Script.
  3. Look for code.gs file and open it.
  4. Replace whole code of code.gs with your edited code
  5. At top right, click Deploy → New Deployment
  6. At top left, click ⚙ → Web app.
  7. Description: Write Description
  8. Executed as: me <YOUR_GOOGLE_ACCOUNT>
  9. Who can access: Anyone
  10. Click Deploy
  11. Note down Deployment ID and URL for future use then click Done.
  12. Somehow if you not able to not down your credentials then, Go to Deploy → Manage Deployment.
