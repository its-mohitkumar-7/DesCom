Software Installation

1. Arduino IDE

The Arduino IDE is the official, open-source software used to write, compile, and upload code to Arduino boards and compatible microcontrollers.

1.1 Installation

  1. Visit official Arduino website. Or use this link.
  2. Click on Download.
  3. Select your Operating System and package format.
  4. Open package and follow on-screen instructions.

2. Espressif Board

Provides ESP32 board support for Arduino IDE and allows the ESP32-CAM firmware to be compiled and uploaded.

2.1 Installation

  1. Open Arduino IDE.
  2. Open Board Manager.
  3. Search for Espressif.
  4. Select version 2.0.17 (Project is tested with this version).

3. LiquidCrystal_I2C

It is an external code library for the Arduino IDE that allows you to control alphanumeric Liquid Crystal Displays (like 16x2 or 20x4 screens) using the I2C communication protocol.

3.1 Installation

  1. Open Arduino IDE.
  2. Click on Library Manager icon.
  3. Search for Liquid Crystal.
  4. Look for LiquidCrystal by Martin Kubovcik, Frank de Brabandar.
  5. Select version 2.0 in dropdown.
  6. Click on Install.

4. ESP32QRCodeReader

Open source library that enables ESP32 microcontrollers equipped with a camera (like the ESP32-CAM) to scan and decode QR codes in real-time.

4.1 Download

  1. Open a web browser and search for ESP32QRCodeReader.
  2. Find the repository by alvarowolfx. Or use this link.
  3. Click on Tags.
  4. Select v1.1.0.
  5. Click on zip icon to download the source code.
  6. Wait for the download to complete.

4.2 Prepare

  1. Extract the .zip file into a directory.
  2. Go to directory > include.
  3. Move .h files to the root of the library directory.
  4. Compress library folder into a .zip file.

4.3 Install

  1. Open Arduino IDE.
  2. Click on Sketch → Include Library → Add .ZIP library.
  3. Select the library .zip file.
  4. Wait for the installation to complete.
